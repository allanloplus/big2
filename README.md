# Allan's 資安大老二・環島攻防戰

四人大老二網頁遊戲。你扮演 **Allan**（TEAM TAIWAN 資安顧問），對手是 AI 小助手 **阿拉蕾**、勒索軟體 **勒索喵**、假投資群組團長 **飆股老師**。

牌桌不是東南西北四個座位，而是一張台灣地圖：

- **出一張牌走一站**：13 張手牌 = 環島 1 號線 13 站，角色會沿著海岸線走路。先出完手牌、第一個回到台北 101 的人拿到「資安認證」。
- **廟口戲台**：台灣正中央的戲台就是出牌區，牌型會顯示資安代號（對子＝雙因子驗證、順子＝攻擊鏈、葫蘆＝3-2-1 備份、鐵支＝零時差攻擊、同花順＝APT 國家級攻擊）。
- **每站一則資安小知識**：基隆海纜、宜蘭雪隧＝VPN、花蓮地震＝BCP、墾丁燈塔＝SOC、高雄港＝OT、雲林布袋戲＝殭屍網路、台中珍奶＝縱深防禦、新竹竹科＝供應鏈安全……Allan 抵達時阿拉蕾會播報。
- **主播台**：Allan 和阿拉蕾像電視主播一樣即時講評，表情跟著台詞變；反派的嘴砲會冒在地圖上。
- **稽核報告與證書**：每局結算是「稽核報告」，剩下的牌是「未修補的漏洞」；總冠軍拿到「資安環島認證證書」，沒拿第一則收到「矯正措施要求單」。

## 怎麼玩

純靜態網站，不需要建置。直接開 `index.html`，或用任何靜態伺服器：

```
npx http-server .
```

規則說明在 `rules.html`（台灣常見玩法：梅花 3 開局；單張、對子、順子、葫蘆、鐵支、同花順；A2345 最小、23456 最大；鐵支與同花順可以越級壓單張和對子）。

## 語音

沿用拱豬夜市與課程影片的聲線：

| 角色 | 聲線 | 設定 |
| --- | --- | --- |
| Allan | `zh-TW-YunJheNeural` | +6%、-2Hz |
| 阿拉蕾 | `zh-TW-HsiaoYuNeural` | +10%、+28Hz |
| 勒索喵 | `zh-TW-HsiaoChenNeural` | -4%、-8Hz |
| 飆股老師 | `zh-TW-YunJheNeural` | +16%、-16Hz |

台詞預先以 edge-tts 合成在 `assets/audio/`，任何瀏覽器聽起來都一樣；沒有音檔的句子會改用瀏覽器內建語音。「設定」可以改選瀏覽器聲線、關掉反派語音。

修改台詞後重新產生配音（只會合成新增或修改過的句子，並刪掉不再使用的音檔）：

```
pip install edge-tts
python3 tools/build_audio.py
```

## 檔案

| 路徑 | 內容 |
| --- | --- |
| `js/engine.js` | 規則引擎：發牌、牌型判斷、比大小、輪流與過牌、計分（純邏輯，Node 可測） |
| `js/ai.js` | 電腦玩家：先把手牌拆成「出牌計畫」再決定出牌或過；也提供「問阿拉蕾」的建議與理由 |
| `js/stations.js` | 環島 13 站：座標、資安主題、阿拉蕾的導航播報 |
| `js/map.js` | 台灣地圖 SVG（刻意畫胖的番薯島）、環島路線、地標圖示 |
| `js/lines.js` | 角色設定與對白腳本 |
| `js/voice.js` | 播放預錄配音，找不到音檔時改用瀏覽器語音 |
| `js/audio-manifest.js` | 台詞與音檔對照表（由 `tools/build_audio.py` 產生） |
| `js/app.js` | 遊戲流程、角色走路、廟口戲台、主播台對話、稽核報告與證書 |
| `css/style.css` | 版面（桌機、矮螢幕筆電、手機） |
| `tools/build_audio.py` | 以 edge-tts 合成所有台詞 |
| `tools/crop_sprites.py` | 從角色設定圖裁出地圖上走路用的側身圖 |
| `assets/img/` | Allan 與阿拉蕾的表情圖（沿用拱豬夜市從同一批設定圖裁好的檔案）、走路圖、勒索喵與飆股老師的 SVG |

## 測試

```
node tests/simulate.js
```

跑規則單元測試（牌型、順子大小、怪物牌、計分、流程）、檢查每句台詞都有預錄配音，再讓 AI 自動對打 400 局，確認每一步都合法、分數總和為 0。
